Designed for deliberate turnover review

What Turnover Guard checks

The panel scans the active sequence and separates automatic blockers, warnings, manual checks and passed categories so review stays visible instead of being hidden behind a single green/red result.

Source conditions

Flags offline or merged media, retimed or reversed audio, disabled clips, muted tracks, and nested/multicam items within the documented top-level scope.

Processing review

Distinguishes confirmed intrinsic clip components from additional processing and keeps useful Technical IDs available for diagnosis.

Freshness and review

Warning acknowledgement stays separate from severity. Track-lock state is never guessed; it remains an explicit manual confirmation that resets with new or stale results.

AAF — Separate WAV

Version 0.1.0 uses one fixed export profile. The profile name describes the package, not compatibility certification for any receiving application.

Audio48 kHz · 24-bit · WAV · separate mono files
Source extentFull sources · trimming off · zero handles
EffectsRendered audio effects off · source PCM preserved in tested cases
SafetyUser-selected output folder · fresh turnover subfolder · no arbitrary overwrite
Interoperability note: Turnover Guard does not claim universal AAF compatibility, audible equivalence, pan reconstruction or effect reconstruction. Test the exported turnover in the receiving workflow that matters to you.

Local-first by design

The plugin has no production telemetry, analytics backend, runtime AI, publisher license server or plugin account. Output access is requested through supported UXP folder selection.

No cloud processing

Sequence inspection and report generation run locally in Premiere.

No hidden repair

Turnover Guard reports conditions and review state; it does not silently rewrite the sequence to force a pass.

Clear support boundary

Version 0.1.0 is supported only on Windows with Premiere Pro 26.3.2. Other hosts and versions are unqualified.
